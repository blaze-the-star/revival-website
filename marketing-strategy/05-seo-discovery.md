# SEO & Discovery Strategy

## Goal
Make Revival easily discoverable through search engines and recommendation algorithms, bringing in organic traffic from readers actively searching for fantasy fiction.

## Understanding Your SEO Opportunity

**The Good News:**
- Web serials/online fiction is actively searched
- Fantasy is a popular genre
- Christian fiction has dedicated audience
- "Free to read" is a strong search modifier
- Long-form content (chapters) is SEO gold

**The Challenge:**
- Competing with established platforms (Wattpad, Royal Road)
- Building domain authority takes time
- Need consistent content creation
- Must understand your audience's search behavior

### Schema Markup

Add structured data to help search engines understand your content:

**Book Schema (Homepage):**
```json
{
  "@context": "https://schema.org",
  "@type": "Book",
  "name": "Revival",
  "author": {
    "@type": "Person",
    "name": "Blaze the Star"
  },
  "genre": ["Fantasy", "Christian Fiction", "Isekai"],
  "bookFormat": "EBook",
  "isAccessibleForFree": true,
  "description": "Your synopsis here"
}
```

**WebSite Schema:**
```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "Revival",
  "url": "https://blog.revival.us.kg",
  "description": "Free online fantasy web serial"
}
```

**Action Item:**
- [ ] Research and implement basic schema markup

### Internal Linking Strategy

**Link Hierarchy:**
```
Homepage
  ├── About Revival

  └── Chapters
       ├── Book 1 Index
       │    ├── Chapter 1.1
       │    ├── Chapter 1.2
       │    └── ...
       └── Book 2 Index (future)
```

**Link Best Practices:**
- Link to previous/next chapters
- Link to character pages when mentioned
- Link to relevant blog posts from chapters
- Use descriptive anchor text ("Read Chapter 1.1" not "click here")
- Keep clicks from homepage to any page under 3

## Off-Page SEO

### Link Building Strategy

**Quality > Quantity:** One link from a respected site beats 100 spam links

**Ethical Link Building Tactics:**

1. **Guest Posting**
   - Reach out to fantasy fiction blogs
   - Offer to write valuable content
   - Include natural link to Revival
   - Target sites with DA 20+

2. **Directory Listings**
   - Web Fiction Guide (webfictionguide.com)
   - Top Web Fiction (topwebfiction.com)
   - Web Serial Wiki
   - Fantasy book directories
   - Christian fiction directories

3. **Community Participation**
   - Reddit (in signature where allowed)
   - Fantasy fiction forums
   - Goodreads (author page, lists)
   - StoryGraph
   - LibraryThing

4. **Author Collaborations**
   - Cross-promote with similar authors
   - "Recommended Reading" page linking to each other
   - Guest appearances on writing podcasts/blogs
   - Anthology participation (if opportunities arise)

5. **Social Media Profiles**
   - Complete profiles with website links
   - Regular posting keeps profiles active
   - Social signals may influence SEO

6. **Press & Features**
   - Reach out to web serial bloggers/reviewers
   - Submit to "best of" lists
   - Local media (human interest angle)
   - Christian media outlets

### Link Building Outreach Template

```
Subject: Collaboration Idea: Fantasy Fiction Content

Blaze the Star
```

**Outreach Tips:**
- Personalize each message
- Offer value first
- Keep it brief
- Follow up once if no response
- Build genuine relationships

## Measuring SEO Success

### Key Metrics

**Traffic Metrics:**
- Organic search traffic (Google Analytics)
- Search impressions and clicks (Search Console)
- Keyword rankings (manual check or tools)
- Referral traffic from other sites

**Engagement Metrics:**
- Bounce rate (lower is better, aim for <70%)
- Time on page (higher is better)
- Pages per session (readers exploring)
- Conversion rate (email signups, chapter reads)

**Authority Metrics:**
- Domain Authority (DA) - Check with Moz
- Backlinks (number and quality)
- Indexed pages (Google Search Console)
